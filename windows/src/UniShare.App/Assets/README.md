# Packaging assets

Square44x44Logo.png, Square150x150Logo.png, Wide310x150Logo.png,
SplashScreen.png and StoreLogo.png are unmodified Microsoft Windows App SDK
sample/template assets. StoreLogo.png is the sample's logo.png, renamed to
match this manifest. These are temporary packaging artwork, not a UniShare logo.

Source: https://github.com/microsoft/WindowsAppSDK-Samples/tree/main/Samples/Input/cs-winui/Assets
License: https://github.com/microsoft/WindowsAppSDK-Samples/blob/main/LICENSE

DemoMountainLake.png is the supplied generated raster reference for the demo
image activity and recent file thumbnail.
